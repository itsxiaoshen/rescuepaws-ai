# RescuePaws AI demo

An AI adoption assistant for a volunteer-run animal shelter. Ask about animals, describe
your household to get matches, or ask about adoption policies.

All animal records and policy documents in this demo are synthetic. To keep costs down,
the demo is limited to a few messages per minute per visitor.

Code, architecture, and evaluation results: https://github.com/itsxiaoshen/rescuepaws-ai
